# 3.9 Skills 专题

> **本专题分两关，预计总耗时**：25 分钟

## 这个专题讲什么

用了 3.5 自定义命令之后，你已经会把高频任务封装成 `/命令`。但自定义命令是你的私人脚本——手动创建、手动放置、不能分发、不能发现。

**Skills 系统**在自定义命令的基础上往前走了一步：带标准化元数据的可安装代理单元。Skill 可以从 GitHub 安装、可以通过 cc switch 跨工具同步、可以公开分享给别人，也能直接用上别人写好的。

这个专题分两关展开：

---

## 本专题两关

| 关卡 | 内容 | 耗时 |
|------|------|------|
| [3.9a 基础关：什么是 Skill](./skills-basics) | Skill 的来龙去脉、和自定义命令的区别、文件结构、如何创建和调用 | 10 min |
| [3.9b 困难关：找到和活用 Skill](./skills-advanced) | 去哪找优质 Skill、让 Claude Code 帮你设计 Skill、复杂 Skill 的设计技巧 | 15 min |

---

## 学完本专题后你将能够

- 解释 Skill 和自定义命令的本质区别
- 创建、调用一个规范的 Skill
- 找到别人写好、适合自己的现成 Skill
- 让 Claude Code 协助你设计复杂 Skill
- 通过 cc switch 把 Skill 同步到多个工具
