# 🧠 进阶使用

> **目标**：在掌握基础操作之后，深入那些最值得长期投入的高价值能力与真实工作流。

## 📜 本章概览

会安装、会对话、会引用文件，已经能解决大量问题。但真正把 Claude Code 用深、用出差距，往往发生在你开始遇到这些需求之后：

- 普通问答不够，需要更深的推理
- 单个 Claude 不够，需要并行处理复杂任务
- 内置能力受限，需要 MCP 扩展
- 想减少重复操作，把工作流自动化
- 想把经验沉淀成可复用的命令和约定

这一章就是围绕这些真实需求展开的——**按需取用，不必通关全部**。

## 🏆 通关战利品

挑你需要的关卡打，你将能够：

- 在复杂问题上主动触发更深入的推理
- 设计多 Agent / Worktree 并行方案，减少顺序等待
- 用 Hooks 构建"编辑后自动格式化 / 测试 / 通知"流程
- 配置 Playwright / GitHub / 数据库等 MCP，扩展 Claude 的能力
- 把高频工作流封装成可复用命令、跨工具同步的 Skill
- 在大型代码库里高效工作，不再被 token 爆炸卡住
- 写出约束清晰的提示词，识别并快速处理失控会话
- 用手机远程接管电脑上的会话
- 用操作系统级沙箱围栏放手让 Claude 连续干活，越界自动拦下

## 🔋 出发前的补给

## 🧭 推荐路线

进阶关可以按需取用。基于你的**目标**来挑选关卡：

- 想要更强推理 / 更稳输出 → 3.1 扩展思考、3.12 提示词进阶
- 想并行干活 / 自动化 → 3.2 多 Agent、3.3 Worktree、3.4 Hooks
- 想给 Claude 扩展能力 → 3.6 多模态、3.7 MCP、3.8 cc switch、3.9 Skills
- 想稳住大项目 / 救场 → 3.11 大型代码库、3.13 调试排错
- 想跨设备干活 → 3.14 远程控制
- 想放手让它连续干又有安全底线 → 3.15 沙箱模式
