# ⚙️ 基础使用

> **目标**：熟练掌握 Claude Code 的核心操作，建立高效的日常工作习惯。

## 📜 本章概览

跑通第一次对话之后，这一章带你把 Claude Code **真正用顺手**：看懂界面、用熟命令、管好权限、把代码喂给它、管理会话与记忆，再到 Hooks、MCP、Git 这些日常常用能力。

14 关覆盖你之后每天都会用到的操作——不必一口气全打，但都值得在用到时回来看。

## 🏆 通关战利品

打完这一章，你将能够：

- 看懂终端界面，随时判断 Claude 在做什么
- 熟练使用斜杠命令和快捷键
- 理解并主动切换权限模式，既高效又安全
- 用 `@` 精准把文件、命令输出喂给 Claude
- 管理上下文与跨会话记忆，让 Claude 不再反复"忘事"
- 用 CLAUDE.md 固化项目约定、用 Hooks 做基础自动化
- 接好 IDE、配好 MCP、看懂 Git——把 Claude Code 接进真实工作流
