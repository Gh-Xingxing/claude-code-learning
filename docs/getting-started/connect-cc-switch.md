# 1.2h cc switch（推荐）

> **目标**：安装 cc switch 桌面工具，用可视化界面管理多个平台的接入配置，告别手改环境变量。

## 本关任务简报

这一关优先适合：

- 打算在多个平台之间切换的用户
- 不想每次都手动改 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_API_KEY`
- 愿意先花 5 分钟装一个 GUI 工具，换来后续切换的便利

如果你只用一个平台，这一关不是必须的——前面的平台页已经讲了最基础的接入方式，用那个方法先跑通第一次对话完全够用。但如果你打算长期在多平台之间移动，现在装好可以省掉后续很多麻烦。

## 通关奖励：解锁以下技能

- 装好 cc switch 桌面工具，用 GUI 管理多平台接入
- 用预设 + 粘贴 Key 的方式添加一个平台，告别手改环境变量
- 主界面 / 系统托盘一键切换平台，并在 Claude Code 里验证生效

---

## 机制解析：它解决什么问题

如果你用过多个平台，应该遇到过这种场景：

- 切换平台 = 手动改 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_API_KEY`，再重开终端
- 同时接多个平台 = 需要记住多套变量值
- 新加一个平台 = 得知道 Base URL 填什么、Key 格式对不对

cc switch 是一个**桌面 GUI 应用**，把这些操作全部可视化：

- 内置 50+ 主流国内外平台预设，选好平台只需粘贴 Key，Base URL 已经内置
- 一键切换，系统托盘也能切，Claude Code 切换后不用重启终端就能生效
- 顺带统一管理 MCP、会话历史

## 开始闯关

### 第 1 步：下载并安装

官方网站（推荐，直接下载对应系统的安装包）：**[ccswitch.io](https://ccswitch.io)**

GitHub 开源仓库（有问题可以提 issue，也能在这里下载各版本安装包）：[github.com/farion1231/cc-switch](https://github.com/farion1231/cc-switch)

打开官网，选你的系统（Windows / macOS / Linux）下载安装即可，装好打开就能进入下一步。

::: warning 认准唯一官方网站
**只有 `ccswitch.io` 是官方指定的网站**，网上还搜得到别的相似域名，注意鉴别内容的真实性。GitHub 仓库地址也认准 `farion1231/cc-switch`。
:::

---

### 第 2 步：认识主界面

安装并打开 cc switch 后，你会看到类似下面这个界面：

![cc switch 主界面：左侧路由开关、顶部当前供应商、右上角 + 按钮](/images/cc-switch/step2-main-ui.png)

界面上有两个常用位置：

- **左上角路由开关**（拨动开关）：控制是否启用 cc switch 的流量路由能力，接入需要代理转发的平台（如 OpenAI）时需要开启
- **右上角 `+` 按钮**：添加新的供应商配置

---

### 第 3 步：添加平台配置

点击右上角 **`+` 按钮**，进入添加供应商界面。

cc switch 内置了 50+ 平台预设，直接点击你要接入的平台名称：

![预设供应商列表，包含 GLM、DeepSeek、MiniMax 等主流国内外平台](/images/cc-switch/step3-presets.png)

选中平台后，进入配置填写页：

![供应商配置页：只需粘贴 API Key，下方配置会自动填充](/images/cc-switch/step3-apikey.png)

**只需要做一件事**：在 `API Key` 输入框里粘贴你从对应平台拿到的 Key，其余信息（Base URL、请求地址）会自动填充。

不知道 Key 在哪里找？点击输入框下方的"获取 API Key"按钮，会跳转到对应平台的 Key 管理页面。

继续往下，还可以自定义模型映射：

![模型映射配置：可选择 Sonnet/Opus/Haiku 各自对应的具体模型，最后点击添加](/images/cc-switch/step3-models.png)

`Sonnet / Opus / Haiku` 对应的是 Claude Code 内部的三档"档位"，这里你可以把它们映射到该平台实际可用的模型。配置好后点右下角**添加**按钮。

以国内常见平台为例，你需要准备的信息：

| 平台 | 在哪里拿 Key | 备注 |
|------|-------------|------|
| 智谱 GLM | 智谱开放平台 → API Key 管理 | 预设名称搜 "Zhipu GLM" |
| MiniMax | MiniMax 开放平台 → 密钥管理 | 预设名称搜 "MiniMax" |
| DeepSeek | DeepSeek 开放平台 → API Keys | 预设名称搜 "DeepSeek" |
| 通义千问 | 阿里云百炼控制台 → API Key | 预设名称搜 "Bailian" |
| 中转站 | 中转站后台 | 选"自定义配置"手动填写 Base URL |

::: tip 如果你想用 OpenAI（GPT）
cc switch 也支持 OpenAI 账号 OAuth 登录，不需要 API Key，直接用 Plus 或 Pro 订阅账号授权。

但由于 OpenAI API 在国内无法直连，需要额外两步：
1. 打开主界面**左上角的路由开关**（拨动为开启状态）
2. 进入 **设置 → 路由 → 全局出站代理**，填写你本地代理的端口号；或点击输入框右侧的放大镜按钮，让它自动扫描本地代理

确保本地代理已正常运行，再回 Claude Code 验证。代理配置详见 [1.1d 网络配置 →](./network)。
:::

---

### 第 4 步：切换到这个平台并启用

添加好之后，有两种方式启用：

**方式一：主界面切换**

选中你刚添加的供应商 → 点击"启用"按钮

**方式二：系统托盘快速切换（更方便）**

找到任务栏（Windows）或菜单栏（macOS）里的 cc switch 图标 → 右键 → 直接点击供应商名称，立即生效，无需打开主界面。

对 Claude Code 来说，切换供应商后通常**不需要重启终端**就能生效。

---

### 第 5 步：在 Claude Code 里验证

切换完成后，回到 Claude Code 做验收：

```text
> /doctor
```

```text
> /model
```

再发一条最简单的测试消息：

```text
> 你好，介绍一下你自己
```

稳定收到回复即为接入成功。

---

## 通关检定

- [ ] cc switch 桌面应用已装好并能打开
- [ ] 至少添加了一个平台配置（粘贴 Key，Base URL 自动填充）
- [ ] 通过主界面或系统托盘切换到该平台并启用
- [ ] 回到 Claude Code，`/doctor` 无报错、`/model` 看到目标模型、对话能稳定回复

全部点亮就算通关 ✓

## 这条路线的优点和边界

**优点**

- 多平台切换不再靠手改环境变量，统一在 GUI 里管理
- 内置 50+ 平台预设，主流国内外平台一键配置
- 系统托盘即时切换，不打断工作流
- 支持 OpenAI Plus/Pro 账号 OAuth 登录（不需要 API Key）
- 顺带管理 MCP、会话历史等

**边界**

- 需要单独安装一个桌面应用
- 不保证所有平台能力完全一致（中转层终究和原生接口有差异）
- 如果你只用一个固定平台，额外装这个工具可能不必要
