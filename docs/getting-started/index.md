# 🚀 快速上手

> **目标**：30 ~ 45 分钟内完成安装、接入模型，并成功发起第一次 AI 对话。

## 📜 本章概览

**还不知道 Claude Code 是什么？** 一句话：它是跑在终端里的 AI 智能体——你只需要告诉它你的需求，它直接帮你读写文件、跑命令、改代码、写文档、做系统等等等等。而且目前**国内使用无门槛**（支持接国产模型，不封号、不用科学上网）。想先完整了解它是什么、有哪些优点，看[首页的介绍 →](/)。

这一章只解决**第一次上手最关键的几件事**：把它装上、接好一个模型、跑通第一次对话、配好 `CLAUDE.md`。

它是整站**最最基础的一章**——这四步没走通，基础使用和进阶使用都无从谈起。所以这章的关卡分两种：**必经主线**和**卡住再看的支线**，主线只有四关，支线在需要的时候随时翻。

## 🔋 出发前的补给

动手前先备齐：

- 一台能联网的电脑（Windows / macOS 都行）
- 至少一种可用的模型接入路线（最不确定"怎么接模型"？1.2 就是专门解决这个的）
- 想入门 Claude Code 的信心和决心

### 先认识"终端"

Claude Code 有两个版本：一个是带图形界面的**桌面软件版**，一个是跑在终端里的**命令行（终端）版**。本网站主要讲**终端版**——它更灵活、能力更全，也是大多数人使用 Claude Code 的方式。

那"终端"是什么？就是一个**用打字输入命令**来操作电脑的窗口（常见是黑底白字的框）。你后面装 Claude Code、跟它对话，都在这里完成。初期使用可能会有不习惯的感觉，但用多了就会发现它其实特别方便。

**在你的系统里打开终端**（点你的系统标签）：

::: code-group

```text [Windows]
以下打开方式可任选一种：
1> 按 Win + X，在左下角弹出的菜单里点(也可通过 ↑ ↓ 键选择)「终端」（或「Windows PowerShell」）
2> 在你的项目文件夹空白处单击右键 → 找到「在终端中打开」—— 这样启动终端会直接定位到这个项目目录，很常用
3> 按 Win 键在搜索框搜索「终端」再打开

补充：Windows 自带的「命令提示符（CMD）」也是终端的一种；用「终端 / PowerShell」都可以跑 Claude Code 
（Win10 右键若没有「在终端中打开」，按住 Shift 再右键 →「在此处打开 PowerShell 窗口」）
```

```text [macOS]
1> 按 Cmd + 空格 打开聚焦搜索，输入「终端」（Terminal）回车
2> 在「访达 → 应用程序 → 实用工具」里找到「终端」
3> 想直接定位到某个文件夹：把文件夹拖到程序坞的「终端」图标上
```

```text [Linux]
1> 快捷键 Ctrl + Alt + T 直接打开
2> 在应用菜单里搜索 "Terminal"
3> 多数文件管理器里，文件夹空白处右键也有「在终端中打开」
```

:::

## 🧭 推荐路线

不用一上来就把 17 关全部打通，**走通这条四关主线就算成功上手**：

> 1.1 安装 → 1.2 接入模型（子页里挑**一条**适合你的平台）→ 1.3 第一次对话 → 1.4 初始化项目

- 装不上 → 1.1b 安装排错（想换 npm 等装法见 1.1a）

- 要走代理 → 1.1d 网络配置
- 接模型只看你选的那条 → 1.2a~1.2h 任选其一
- 想升级或遇到报错 → 1.5 更新与排错
