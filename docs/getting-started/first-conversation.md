# 1.3 第一次对话

> **预计耗时**：15 分钟

## 本关任务简报

前面两步做完之后，这一关要解决的就是：

- 让你真正进入 Claude Code
- 发出第一条消息
- 理解最基础的交互方式

也就是说，这一关不是讲所有高级能力，而是帮你完成“第一次可用对话”之后的最小认知建立。

## 通关奖励：解锁以下技能

- 走完首次启动的四步初始化配置
- 进入 Claude Code 并发出第一条消息、看懂界面三大区域
- 上手两个最常用的基础动作：`@` 引用文件、`!` 执行命令
- 知道怎么中断生成、退出、清空对话

---

## 开始前先检查装备

默认你已经完成前两关：

- `1.1 安装`：`claude --version` 可以正常输出
- `1.2 接入模型`：`/doctor` 基本正常，没有明显报错

如果这两步还没通，先不要急着学界面操作。

---

## 开始闯关

### 启动 Claude Code

**建议先进入你的工作目录再启动**，而不是在系统根目录直接输入 `claude`。这样 Claude Code 默认只在这个文件夹下工作，上下文更干净，回答也更准确：

```bash
cd 你的项目目录
```

```bash
claude
```

---

### 首次启动：四步初始化配置

第一次运行 `claude` 时，会依次出现四个初始化提示，按顺序配置一遍即可：

#### 第一步：选择颜色主题

Claude Code 会展示几种配色方案供你预览，每个选项下方都有代码效果示例。

按方向键选择你喜欢的主题，按 `Enter` 确认。

> 以后想换主题，随时在 Claude Code 里输入 `/theme` 重新选择。

#### 第二步：阅读安全提示

界面会显示两条使用须知：

- Claude 可能犯错，它生成的代码和要执行的命令，建议你过一眼再放行
- 只在你信任的代码库里使用 Claude Code，防范提示词注入攻击

直接按 `Enter` 进入下一步。

#### 第三步：终端设置

Claude Code 会询问是否启用推荐的终端设置，推荐直接接受（按 `Enter`）。

这一步会启用两个功能：

- **换行快捷键**：启用后在输入框里按 `Shift+Enter` 换行（macOS 也支持 `Option+Enter`），不会意外提交
- **Visual Bell**：Claude 跑完任务或需要你操作时，终端窗口会闪烁提醒，不用盯着屏幕等

> 如果后续想手动开启，可以在 Claude Code 里运行 `/terminal-setup`。

#### 第四步：确认目录信任

Claude Code 会确认当前目录是否可信任，允许它读写其中的文件。

选择"是"，按 `Enter`。

---

### 进入后先做一次最小验证

直接发一句最简单的话：

```text
> 你好，介绍一下你自己
```

只要能正常回复，就说明你已经不只是“装好了”，而是真的进入了第一次可用对话。

---

### 你进入后会看到什么

进入后你会看到：

- 顶部：当前模型和权限模式
- 中间：对话历史区域
- 底部：输入提示框（`>`）

第一次不用把所有区域都研究透，先知道：

> 你真正最常交互的地方，就是底部输入框。

---

### 再试一个更像真实使用的问题

直接在提示框输入，按 `Enter` 发送：

```text
> 你好，介绍一下你自己，并告诉我现在最适合先学什么
```

这个问题的意义不是内容本身，而是帮你确认：

- 模型确实接通了
- 对话真的能稳定进行
- Claude Code 已经进入可用状态

---

### 两个最值得先学的基础动作

#### 1）引用文件：`@`

```text
> @package.json 帮我分析一下这个项目的依赖
```

`@` 后接文件路径，Claude 会读取文件内容作为上下文。

这是你后面最常用的能力之一，因为它决定了 Claude 看到的是“泛泛而谈”，还是“基于你的真实文件回答”。

#### 2）执行命令：`!`

```text
> !ls -la
> 帮我分析一下当前目录的文件结构
```

`!` 前缀让 Claude 执行 shell 命令，并将输出作为上下文注入对话。

如果你是 Windows 用户，后面实际用的时候也可以按自己常用终端命令来写，不必死记这个例子本身。

---

### 中断与退出

| 操作 | 快捷键 |
|------|--------|
| 中断当前生成 | `Escape` |
| 强制终止工具执行 | `Ctrl+C` |
| 退出 Claude Code | `Ctrl+D` 或输入 `/exit` |

### 清空对话

```text
> /clear
```

清除当前对话历史，释放上下文窗口。
