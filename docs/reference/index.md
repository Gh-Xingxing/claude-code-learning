# 🧰 工具箱

> **目标**：快捷键、命令、参数、配置、平台接入、环境变量、报错——需要时随手一查，不必翻正文。

## 📦 箱子里有什么

| 工具 | 装着什么 |
|------|---------|
| [A. 快捷键速查](./keyboard-shortcuts) | 所有内置快捷键，按操作类型分组 |
| [B. Vim 模式速查](./vim-mode) | 开启 Vim 编辑模式后的全部按键 |
| [C. 斜杠命令速查](./slash-commands) | 所有 `/` 命令完整列表，含参数说明 |
| [D. CLI 参数速查](./cli-flags) | 启动 Claude Code 时可用的所有标志 |
| [E. 配置选项速查](./config-options) | `settings.json` 所有可配置字段 |
| [F. 平台接入速查](./platforms) | 各平台 Base URL、模型名、认证变量一张表 |
| [G. 环境变量速查](./env-vars) | `ANTHROPIC_*` / `CLAUDE_CODE_*` / 代理变量集中查 |
| [H. 错误信息速查](./errors) | 常见报错 → 原因 → 怎么办，快速定位 |

## 💡 取用技巧

- 用浏览器的 `Ctrl+F` / `Cmd+F` 在页内搜索关键词
- 点击顶部"本页目录"快速跳转到对应分组
- 所有表格可以横向滚动查看完整内容
