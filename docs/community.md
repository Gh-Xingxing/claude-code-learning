## 加入能得到什么

- **遇到问题随时问**：装不上、模型连接失败、执行任务报错……都可以在群聊里讨论交流。
- **第一时间知道更新动态**：新关卡、新内容上线会在这里同步。
- **一起探讨**：分享各自的配置、Skill、工作流及使用经验，少走弯路。

## 进群注意事项

1. 🤝 **对新手友好**：互相尊重，不嘲笑任何"小白问题"，不抬杠、不人身攻击。都是闯关路上的同路人。
2. 🙋 **提问问题表达清楚**：可从系统(Win/Mac)、卡在哪一步、报错原文、想要实现什么效果等方面来表述。也请认真阅读闯关指南，尽量不要提问指南网站里已有讲解的内容。
3. 🚫 **禁止发广告、引流等行为**：任何广告、招募推广以及恶意私加引流等行为，如有发现一律移出群聊。
4. 💬 **交流主要内容**：欢迎探讨交流 Claude Code 使用、AI 工具、模型等话题内容。
5. 🔒 **注意隐私**：提问交流时注意保护自己的个人隐私。不要泄露自己或他人的信息，API key 等相关内容不要轻易分享给他人。
6. ⚖️ **对群规有疑问可私信群主**：如遇到私加骚扰、广告 / 引流刷屏等问题，可直接 @ 或私信群主处理。
