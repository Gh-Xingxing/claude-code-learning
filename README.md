## 💻 现在开始

**在线阅读（推荐）**：📘 <https://claudecodelearning.com>

**本地运行**：

```bash
git clone https://github.com/Gh-Xingxing/claude-code-learning.git
```

```bash
cd claude-code-learning
npm install
```

```bash
npm run dev
```
